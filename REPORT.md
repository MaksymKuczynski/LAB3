## 3. Висновки
> *Під час виконання лабораторної роботи було створено програму для обробки та аналізу медичних даних про пацієнтів, їхні діагнози та призначення. Практично застосовано вбудовані функціональні оператори: filter() — для відбору пацієнтів за діагнозом, map() — для форматування імен, reduce() — для підрахунку підсумкової вартості лікування.*
